# EzShop: Android E-Commerce App

![Android](https://img.shields.io/badge/Android-3DDC84?style=flat-square&logo=android&logoColor=white)
![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![Firebase](https://img.shields.io/badge/Firebase-FFCA28?style=flat-square&logo=firebase&logoColor=black)

A full shopping app for Android, with a customer storefront and a built-in admin panel, backed by Firebase.

## Features

**Customers**
- Sign up and log in
- Home page with banners, promotions, categories and recommendations
- Explore and search products, with trending searches
- Product details with images, colour options and reviews
- Wishlist, cart and checkout
- Order history, notifications and profile

**Admin**
- Dashboard
- Add, edit and delete products
- Manage categories
- View and manage orders

## Tech stack

Java · Android SDK · Firebase (authentication and database) · Glide · Gradle (Kotlin DSL)

## Getting started

1. Open the project in **Android Studio**.
2. Create a Firebase project, add an Android app with the package name `com.example.ezshopapp`,
   and place your own `google-services.json` in `app/`.
3. Sync Gradle and run on an emulator or a device.
